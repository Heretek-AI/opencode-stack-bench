---
name: test-first
description: PLACEHOLDER skill. Use when implementing or fixing behaviour described in a spec, to write edge-case tests before changing code.
---
1. Turn every rule in the task statement into at least one test case, including error cases.
2. Run the tests and confirm the new ones fail for the right reason.
3. Implement the change, then run the full test suite until it passes.
4. Delete nothing you did not create unless the task asks for it.
